# Continuous / Binary / Count Response

## Question
continuous / binary / count response ei gular mane ki and parthorko ki?

## Answer
এগুলো হলো response variable বা dependent variable-এর বিভিন্ন ধরন।

- Continuous response:
  - এ ধরনের variable-এর মান continuous হয়, অর্থাৎ decimal বা real number হতে পারে।
  - উদাহরণ: height, weight, temperature, income.
  - সাধারণত linear regression দিয়ে model করা হয়।

- Binary response:
  - এ ধরনের variable-এ কেবল দুইটি possible outcome থাকে।
  - উদাহরণ: yes/no, pass/fail, 0/1, diseased/not diseased.
  - সাধারণত logistic regression দিয়ে model করা হয়।

- Count response:
  - এ ধরনের variable-এ counting data থাকে, অর্থাৎ non-negative integer সংখ্যা হয়, যেমন 0, 1, 2, 3, ...
  - উদাহরণ: number of accidents, number of children, number of visits.
  - সাধারণত Poisson regression অথবা negative binomial regression দিয়ে model করা হয়।

### Simple idea
- Continuous = পরিমাপ করা amount
- Binary = দুইটি category
- Count = কোনো কিছু কতবার ঘটছে তার সংখ্যা
