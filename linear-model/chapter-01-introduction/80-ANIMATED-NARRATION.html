The one sentence

Everything in this course comes back to this

y = f(x) + ε
f(x) — systematicthe signal, the structured part
ε — randomthe noise, unexplained
Regression separates signal from noise. Every later chapter is detail about the shape of f, or the assumptions on ε.

"Linear" means linear in β

Not a straight line — a statement about how β enters the model

✅y = β₀ + β₁x + β₂x² + ε  (polynomial)
✅y = β₀ + β₁ log(x) + ε
✅y = β₀ + β₁x₁ + β₂x₂ + β₃x₁x₂ + ε  (interaction)
❌y = β₀ + x^β₁ + ε  (β inside a nonlinear function)

R² in simple regression

One covariate only — R² = r²

R² = r²
R² = 0.038  ⟹  r = √0.038 = 0.195
sign taken from β̂₁ — the square root alone never supplies it

Notation, and the p-trap

y = Xβ + ε

y = Xβ + ε
X: n×p, one row per observation, one column per parameter — first column all 1s
⚠ the p-trapBook: p = k+1 (incl. intercept) · Some papers: p = k (covariates only)
Defence: count the β's yourself, incl. intercept — write n−k−1
