The frame

Regression models the conditional mean

E(y | x) = f(x)
y = f(x) + ε,   E(ε) = 0  ⟹  always say "expected"
η = x'β  (linear predictor)
E(y) = ηlinear model
P(y=1) = h(η)logit — squashed into (0,1)

2.2.1 Simple linear regression

One covariate — a slope and an intercept

β̂₁ = Cov(x,y) / Var(x) = r·(sᵧ/sₓ)
β̂₀ = ȳ − β̂₁x̄
the line always passes through (x̄, ȳ)

Interpreting the slope — and NOT the intercept

Four checkable parts · centre before interpreting β₀

"A one-unit increase in x is associated with an estimated β̂₁ unit change in the expected y, holding other covariates fixed."
Don't interpret β̂₀ unless x=0 is meaningful & in range. Age=0 isn't.
Fix: centre — (age − 48) → β̂₀ becomes "expected wage at 48".

Polynomial regression

Still linear in β — but the effect changes with x

y = β₀+β₁x+β₂x²+ε
effect = β̂₁ + 2β̂₂x  (not β̂₁ alone)
turning point x* = −β̂₁/(2β̂₂)

2.2.2 Multiple regression

Every coefficient becomes a partial effect

y = x'β + ε
β̂ⱼ is the partial effect — holding ALL other covariates fixed.
Partial and marginal (simple) correlation can have OPPOSITE signs.

Dummy variables

c levels ⟹ c−1 dummies — never c

0< HS Grad — the reference
1HS Grad  +$11.01
2Some College  +$23.16
3College Grad  +$37.97
4Advanced Degree  +$62.63
The dummy trap All c dummies + intercept ⟹ columns sum to the intercept ⟹ X'X singular ⟹ no unique OLS.

Comparing two non-reference levels

Subtract — never quote one coefficient alone

Δ = β̂A − β̂B
Advanced Degree vs HS Grad
62.63 − 11.01 = 51.62
not 62.63 alone — that compares to the REFERENCE, not to HS Grad

Interactions

Dummy shifts the line. Interaction tilts it.

Why linear regression fails for binary y

Four connected reasons

1predictions can escape [0, 1] — 1.34, −0.20
2Var(y) = π(1−π) — heteroscedastic by construction
3ε takes only two values — never normal
4constant effect implausible near 0 and 1

The logit link — three equivalent forms

Uncaging the probability, twice

probabilityπ ∈ [0,1]
bounded both sides
➜
oddsπ/(1−π) ∈ (0,∞)
bounded below only
➜
log-oddslog(π/(1−π)) = η = x'β
unbounded — linear here

Logit interpretation: the odds ratio

Pick the right scale

ScaleEffect of +1 in xⱼ
log-odds+β̂ⱼ (exact, constant)
odds×exp(β̂ⱼ) — the odds ratio
probabilityβ̂ⱼ·π(1−π) — NOT constant
exp(0.028) ≈ 1.028 → +2.8% odds  |  exp(−0.85) ≈ 0.427 → odds fall >50%

The biggest trap in this chapter

Read it to the very end

❌ FALSE
"β̂ⱼ increases P(y=1) by β̂ⱼ."
confuses the log-odds scale with the probability scale — only the SIGN transfers reliably
