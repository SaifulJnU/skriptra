# 99 — EXAM VAULT

**This folder is not for learning. It is for retrieval.**

By the time you open anything in here, you should already have read the chapters. The vault exists for one purpose: to get what is in your head **out** of it, fast, under time pressure, in the shape the exam wants.

| File | What it is | When the master plan calls for it |
|---|---|---|
| `10-FORMULA-SHEET.md` | Every formula you must be able to reproduce | **Day 20** — write it out from memory 3× |
| `20-QUESTION-BANK.md` | Exam-style questions sorted by the four exercise blocks | Days 13, 16, 18, 19 (between mocks) |
| `30-TRUE-FALSE-DRILL.md` | 72 T/F statements with reasons | **Day 15**, then the morning of the exam |

---

## How to use each one

### `10-FORMULA-SHEET.md` — the blank-page test

**Do not read this file.** Reading it feels productive and does almost nothing.

Instead: close it, take a blank sheet, and reproduce it in the order given in its §0. Then open the file and mark yourself. The gap between what you wrote and what is here **is your revision list** — nothing else in the vault matters as much as that gap.

Three full reproductions on Day 20. The third one should take under 15 minutes.

### `20-QUESTION-BANK.md` — pattern recognition

The exam has four blocks and they barely change year to year. This file is those blocks, drilled separately, so that in the exam you are **recognising** a question type rather than meeting it.

Work a block, then check. Never read the answer first.

### `30-TRUE-FALSE-DRILL.md` — the cheapest 6 marks

Exercise 1 is 6 points for 12 statements and needs no computation. It is the highest marks-per-minute block on the paper, and it is pure recall of things you either know or don't.

The drill is built so you answer all 72 **without** seeing the reasons, then check. The reasons matter more than the verdicts — if you got it right for the wrong reason, you will get the next variant wrong.

---

## The three rules this folder is built on

1. **Recognition, not derivation.** 60 marks in 60 minutes. You cannot work anything out from first principles on the day. Everything here should be something you *recall*, not something you *compute from scratch*.

2. **Formula before numbers.** Every past-paper marking key awards points for method. This is why the formula sheet is a reproduction exercise and not a reference card — you need the formula available *before* you know what the numbers are.

3. **Never leave a T/F blank.** Negative marking is floored at zero per block. A guess has positive expected value and no downside. This single fact is worth more than any individual piece of content in this folder.
