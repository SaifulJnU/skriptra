# Chapter 3: Hypothesis Spaces and Capacity — Practice True/False Questions

## Questions

**Q1.** Underfitting refers to the failure to obtain a sufficiently low training error.

**Q2.** Overfitting refers to a large difference between training and test error.

**Q3.** The generalization gap is the gap between the training error and the generalization (test) error.

**Q4.** The tendency of a model to over/underfit is a function of its capacity.

**Q5.** A model with low capacity can learn many complex hypotheses.

**Q6.** Test error is minimized when the model has the highest possible capacity.

**Q7.** The hypothesis space (representation) is the space of allowed models for a learner.

**Q8.** A separating hyperplane classifier has the form h(x | θ₀, θ) = 1(xᵀθ − θ₀ > 0).

**Q9.** Decision trees recursively divide the feature space into axis-aligned rectangles.

**Q10.** In a neural network, each neuron computes a weighted sum of its inputs followed by a non-linear transformation.

**Q11.** Ensemble methods aggregate the predictions of several models.

**Q12.** Increasing the degree of a polynomial decreases the capacity of the model.

**Q13.** Increasing the size of the hypothesis space usually increases the number of learnable parameters.

**Q14.** As the size of the hypothesis space increases, the tendency to overfit increases.

**Q15.** In the polynomial regression example, the degree-13 model achieved the lowest training error but a huge test error.

**Q16.** As model capacity increases, training error tends to keep decreasing.

**Q17.** As model capacity increases, test error decreases monotonically.

**Q18.** For k-nearest neighbours, a smaller k corresponds to higher capacity.

**Q19.** For decision trees, a larger `minsplit` corresponds to higher capacity (more overfitting).

**Q20.** The VC dimension is a measure of the complexity of a function space.

**Q21.** A set of points is shattered by a class of functions if some member can perfectly separate them for every possible binary labeling.

**Q22.** If the VC dimension of a hypothesis class is d, then every set of d points can be shattered.

**Q23.** If the VC dimension is d, there exists at least one shatterable set of size d and no shatterable set of size d+1.

**Q24.** The class of linear indicator functions in ℝ² has VC dimension 3.

**Q25.** The VC dimension of homogeneous halfspaces in ℝᵖ is exactly p.

**Q26.** The VC dimension of non-homogeneous halfspaces in ℝᵖ is exactly p.

**Q27.** The class of axis-aligned rectangles in ℝ² has VC dimension 4.

**Q28.** A single-parametric threshold classifier h(x) = 1(x ≥ θ) has VC dimension 1.

**Q29.** A single-parametric sine classifier h(x) = 1(sin(θx) > 0) has VC dimension 1, since it has only one parameter.

**Q30.** For 1-nearest neighbour (k = 1), the VC dimension is infinite.

**Q31.** The VC dimension can always be judged solely from the number of model parameters.

**Q32.** The training error is an optimistic estimate of the generalization error.

**Q33.** The VC generalization bound holds only for one particular data distribution P_xy.

**Q34.** If the VC dimension d is finite, both δ and ε in the VC bound can be made arbitrarily small by increasing the sample size.

**Q35.** An algorithm that reliably picks a good hypothesis by minimizing training error is called a Probably Approximately Correct (PAC) algorithm.

**Q36.** VC bounds are typically tight and optimistic.

**Q37.** Rademacher complexity is an alternative measure of model capacity that can give tighter bounds.

**Q38.** In the bias-variance decomposition, the data is assumed to be generated by y = f_true(x) + ε with ε ~ N(0, σ²) independent of x.

**Q39.** The L2-loss bias-variance decomposition splits the generalization error into three terms: data variance, inducer variance, and squared bias.

**Q40.** The σ² term (variance of the data) is the irreducible/unavoidable error that no learner can get below.

**Q41.** The variance term of the inducer captures the learner's tendency to overfit.

**Q42.** The squared bias term captures the learner's tendency to consistently misclassify (underfitting).

**Q43.** Models with high capacity have high bias and low variance.

**Q44.** As capacity increases, error due to variance increases and error due to bias decreases.

**Q45.** As the training-set size grows, the error due to variance vanishes and the generalization gap shrinks.

**Q46.** To reduce overfitting (high variance), you can make the model less flexible (regularization) or add more data.

**Q47.** To reduce underfitting (high bias), you should add more regularization.

**Q48.** Machine learning is an ill-posed problem because unseen datapoints can have any labels, leaving many consistent functions after observing the training data.

**Q49.** The No Free Lunch theorem states that, averaged over all possible problems, no algorithm is better than any other (including random guessing).

**Q50.** According to NFL, there exists an algorithm that is universally better than all others on every problem.

**Q51.** Without making any assumptions about the problem, machine learning is still possible and effective.

## Answers

| Q | Answer | Key Reason |
|---|--------|------------|
| 1 | **TRUE** | Definition of underfitting |
| 2 | **TRUE** | Definition of overfitting |
| 3 | **TRUE** | Generalization gap = train↔test gap |
| 4 | **TRUE** | Over/underfit is a function of capacity |
| 5 | **FALSE** | Low capacity → only a few **simple** hypotheses |
| 6 | **FALSE** | Minimized at **optimal** (intermediate) capacity, not highest |
| 7 | **TRUE** | Representation = hypothesis space |

| 9 | **TRUE** | Trees split into axis-aligned rectangles |
| 10 | **TRUE** | Weighted sum + non-linear σ |
| 11 | **TRUE** | Definition of ensemble methods |
| 12 | **FALSE** | Higher degree → **higher** capacity |
| 13 | **TRUE** | Bigger H usually → more parameters |
| 14 | **TRUE** | Bigger H → more overfitting tendency |
| 15 | **TRUE** | Degree 13: train RMSE 0.48, test RMSE 148.5 |
| 16 | **TRUE** | Training error keeps dropping with capacity |
| 17 | **FALSE** | Test error is **U-shaped**, not monotone |
| 18 | **TRUE** | Smaller k → higher capacity |
| 19 | **FALSE** | **Smaller** minsplit → higher capacity |
| 20 | **TRUE** | VC dimension measures complexity |
| 21 | **TRUE** | Definition of shattering |
| 22 | **FALSE** | Only **at least one** set of size d, not all |
| 23 | **TRUE** | Correct definition of VC dimension |
| 24 | **TRUE** | Linear indicators in ℝ²: VC = 3 |
| 25 | **TRUE** | Homogeneous halfspaces: VC = p |
| 26 | **FALSE** | Non-homogeneous: VC = **p+1** |
| 27 | **TRUE** | Axis-aligned rectangles in ℝ²: VC = 4 |
| 28 | **TRUE** | Threshold classifier: VC = 1 |
| 29 | **FALSE** | Sine classifier has **infinite** VC dimension |

| 46 | **TRUE** | Reduce variance: regularization or more data |
| 47 | **FALSE** | Reduce bias by making model **more** flexible, not more regularization |
| 48 | **TRUE** | ML is ill-posed; many consistent functions remain |
| 49 | **TRUE** | No Free Lunch theorem |
| 50 | **FALSE** | NFL: **no** universally-best algorithm |
| 51 | **FALSE** | Without assumptions/prior, ML isn't possible |
